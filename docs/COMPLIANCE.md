# 合规与声明（COMPLIANCE.md）

> 本文件是本仓库**唯一权威的"对外陈述规范"**：任何报告中引用的数字/结论，都必须按本文件分级并附证据路径。本文不是评审意见，是写作纪律。

## 1. 交付主体与器件合规

- 参赛赛道：全国大学生嵌入式芯片与系统设计竞赛 · FPGA 创新设计赛道 · **紫光同创杯 · 赛题一「基于 RISC-V 处理器的软硬件系统设计」**。
- **交付主体器件 = 紫光同创 PG2L100H**（Logos2 / -6 / FBG676；PDS 2022.2-SP6.1）。赛题要求交付主体落在紫光同创器件上。
- 本仓库同时保留 **Artix-7 XC7A100T** 参照线（Vivado）。按赛题规则（跨厂商仅作对比），**Artix 的任何数字不构成交付成绩**，只能出现在"跨厂商对比"章节，并显式标注 `[跨厂商对比]`。
- 禁止：把 Artix 的 CoreMark/频率/NPU 数字写成"本项目成绩"；把 Pango 上未测的项写成"已完成"。

## 2. 证据分级（每个数字必须带级别 + 证据路径）

| 级别 | 含义 | 必须附带 |
|---|---|---|
| **A 实测（上板）** | 真实板卡运行/测量 | 板卡型号、日期、位流 SHA256、原始日志/串口输出、测量条件 |
| **B 实测（仿真）** | ModelSim/板级仿真通过 | 测试名、PASS 计数、日志路径、被测 RTL/程序版本 |
| **C 综合/实现** | 综合或 P&R 报告 | 工具+版本、约束（周期/频率）、WNS/fmax、资源报告路径 |
| **D 派生/推算** | 由 A/B/C 计算得到 | 公式 + 输入值 + 输入证据路径 |
| **E 计划/未测** | 尚未完成 | 必须写"未达成/未测/待"，禁止省略 |

允许的写法示例：`CoreMark 324.19（A 实测，2026-10-17，位流 sha256 `16578a25…`，日志 results/uart_flash_boot_final.txt）`。
禁止的写法示例：`CoreMark 405.9`（无级别）、`NPU 已上板`（无证据）、`零误检`（绝对化）。

## 3. 禁止/限制用语

- 禁止绝对化与营销化：**零误检、工业级、通用 YOLO 移植、100% 正确、保证识别、已量产、商用**。
- 禁止把"仿真/综合/派生"写成"实测/已上板"。
- 禁止把**未部署**的应用写成"已部署"（当前 COCO80 未在板上部署；手势识别为实验分支，约 35% 正确率）。
- 禁止把 **Pango Flash** 写成"已写入/可断电自启动"（当前仅 JTAG RAM 下载）。
- 数值必须带单位与口径（如 CPU 125 MHz / NPU 50 MHz；NPU 1,769,238 周期为"纯计算"）。

## 4. 交付边界清单（必须在报告/演示中显式声明）

**已达成（有证据）**
- PG2L100H（**当前烧录版 = 95 MHz 双发射**，位流 `51f5eda2…`）：CPU/IMEM/DMEM 95 MHz（WNS +0.493）、NPU/采集/MMIO 50 MHz；LUT 9980/FF 6573/APM 13/DRM 99。上一版为 125 MHz 单发射（WNS +0.609，LUT 4469/FF 3706/APM 10/DRM 64，位流 `f179a403…`），仅作历史对照。详见 `fpga_pg2l100h/vision/CURRENT-BUILD.md`。
- 芯片 ID/DONE/配置错误位/PLL 锁定；摄像头→LCD 预览目视确认；位流 SHA256 已记录。
- 自研 INT8 NPU 纯计算 1,769,238 周期 @50 MHz = 35.38 ms（应用：NUMGUARD 数字标签核验）。
- Artix 参照线：150 MHz 交付档 WNS +0.007、QSPI Flash 自启动（2026-10-17）、CoreMark 324.19（实测，`-Os` 旧固件）[跨厂商对比]。

**未达成 / 未部署（不得含糊）**
- **Pango Flash 未写入**（断电需重新 JTAG 下载）。
- CPU 固件执行 / 物理按键 / 应用 UART 尚未逐项确认（摄像头预览可独立于 CPU 运行）。
- 手势识别实验约 35%，不作可靠识别宣称；COCO80 未在板上部署。
- 无 OS/RTOS、无 MicroPython/Arduino 移植、无自研 IDE。
- 无 I-Cache、无板上中断演示。
- 设计报告（Word/PDF）与演示视频尚未产出（截至 2026-11-03）。
